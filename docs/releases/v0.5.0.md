# Local Model Gateway v0.5.0

This release adds first-class managed music generation without creating a
second GPU admission path.

## Highlights

- Call `POST /v1/audio/speech` from scripts and OpenAI-style clients.
- Discover audio-capable models through `supports_audio` metadata.
- Keep music requests inside the existing priority queue, runtime residency,
  cancellation, history, and telemetry system.
- Reproduce the tested MiniMax Music 3 setup on Apple Silicon with the included
  experimental adapter.

## Upgrade

Use Node 22, then rebuild the workspace:

```bash
git pull
npm install
npm run build
npx local-model-gateway doctor --json
```

Add `supports_audio: true` only to managed runtimes that implement
non-streaming WAV output at `POST /v1/audio/speech`. Existing text runtimes
default to `false` and continue to work unchanged.

No model weights are bundled. Follow the
[MiniMax Music 3 adapter guide](../../examples/runtime-adapters/minimax-music3/README.md)
to install the tested runtime, or connect another compatible managed runtime.
